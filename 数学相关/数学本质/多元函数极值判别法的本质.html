多元函数极值判别法的本质：二次函数判别式（2026.9.9）

教材中给出的二元函数极值判别法如下：

设 z=f(x,y)z = f(x, y)z=f(x,y) 在驻点 (x0,y0)(x_0, y_0)(x0​,y0​) 处一阶偏导全为 0。记二阶偏导数为 A=fxx,B=fxy,C=fyyA = f_{xx}, B = f_{xy}, C = f_{yy}A=fxx​,B=fxy​,C=fyy​：

  • 当 AC−B2>0AC - B^2 > 0AC−B2>0 且 A>0A > 0A>0 时，为极小值；
  • 当 AC−B2>0AC - B^2 > 0AC−B2>0 且 A<0A < 0A<0 时，为极大值；
  • 当 AC−B2<0AC - B^2 < 0AC−B2<0 时，无极值（鞍点）。

死记这组字母条件很容易弄混。其实，这个结论就是初中数学里一元二次方程“判别式 Δ<0\Delta < 0Δ<0（曲线不穿过横轴）”的直接推论。

以下是具体的对应过程：

1. 极值取决于二阶增量

在驻点处，切平面是水平的。此时若向任意方向迈出微小一步 (Δx,Δy)(\Delta x, \Delta y)(Δx,Δy)，高度的变化量 Δz\Delta zΔz 完全由二阶泰勒展开项决定：

Δz≈12[A(Δx)2+2BΔxΔy+C(Δy)2]\Delta z \approx \frac{1}{2} \left[ A(\Delta x)^2 + 2B \Delta x \Delta y + C (\Delta y)^2 \right] Δz≈21​[A(Δx)2+2BΔxΔy+C(Δy)2]

  • 要有极小值：往任何方向走，高度都必须上升（Δz\Delta zΔz 恒正）。
  • 要有极大值：往任何方向走，高度都必须下降（Δz\Delta zΔz 恒负）。
  • 如果是鞍点：某些方向上升，某些方向下降（Δz\Delta zΔz 有正有负）。

核心问题变成：如何让括号里的式子在任何方向上都不变号？

2. 化为一元二次函数

我们提出 (Δy)2(\Delta y)^2(Δy)2，并把行进方向的斜率记为 t=ΔxΔyt = \frac{\Delta x}{\Delta y}t=ΔyΔx​：

A(Δx)2+2BΔxΔy+C(Δy)2=(Δy)2⋅(At2+2Bt+C)A(\Delta x)^2 + 2B \Delta x \Delta y + C (\Delta y)^2 = (\Delta y)^2 \cdot (A t^2 + 2B t + C) A(Δx)2+2BΔxΔy+C(Δy)2=(Δy)2⋅(At2+2Bt+C)

因为 (Δy)2(\Delta y)^2(Δy)2 永远是正数，所以 Δz\Delta zΔz 到底是正还是负，完全取决于一元二次函数 g(t)=At2+2Bt+Cg(t) = A t^2 + 2B t + Cg(t)=At2+2Bt+C 的正负。

3. 结论的直接对应

为了保证函数 g(t)g(t)g(t) 在任何方向 ttt 上都不变号（即抛物线不穿过横轴，没有实数根），它的判别式必须小于 0：

Δ=(2B)2−4AC<0\Delta = (2B)^2 - 4AC < 0 Δ=(2B)2−4AC<0

两边同除以 −4-4−4，不等号反转，直接得到：

AC−B2>0AC - B^2 > 0 AC−B2>0

这解释了为什么必须是 AC−B2>0AC - B^2 > 0AC−B2>0：它仅仅是为了保证增量不穿轴变号。

在保证了不穿轴之后：

  • 看 A>0A > 0A>0：二次项系数大于 0，抛物线开口向上，增量恒正   ⟹  \implies⟹ 极小值。
  • 看 A<0A < 0A<0：二次项系数小于 0，抛物线开口向下，增量恒负   ⟹  \implies⟹ 极大值。
  • 反之，若 AC−B2<0AC - B^2 < 0AC−B2<0：说明 Δ>0\Delta > 0Δ>0，抛物线穿过横轴，增量有正有负   ⟹  \implies⟹ 无极值（鞍点）。

结语

多元函数极值判别法中那些容易记混的条件，本质上只是“二次函数判别式 Δ<0\Delta < 0Δ<0”和“抛物线开口方向”在多元微积分里的“套壳表达”。

下次做题如果不慎忘记或者记混了公式，完全不需要凭感觉瞎猜。只需在草稿纸上写下 At2+2Bt+CAt^2 + 2Bt + CAt2+2Bt+C：

  1. 算出 Δ<0\Delta < 0Δ<0，自然得出 AC−B2>0AC - B^2 > 0AC−B2>0（锁定极值存在）；
  2. 看一眼 AAA 的正负，自然得出抛物线开口（锁定极大还是极小）。

抓住“高度增量不能穿轴变号”这个几何直观，看似生硬的代数结论就会变成自然而然的常识。
