# MOS 教程

从零用 Rust 在 x86_64 上写一个能跑在真机（UEFI 启动）上的自制操作系统。

> **配套开源项目**：[minecraftbucuo/MOS](https://github.com/minecraftbucuo/MOS) —— 教程中每一步对应的完整代码都在这个仓库里，建议对照着看。

## 引言

（2026.9.11）

---

相信每一个对电脑感兴趣的人都有这个疑问，操作系统是怎么开发出来的？它虽然也被定义为程序，但却和其他普通程序有着巨大差异，我们开发其他应用程序，天然可以调用系统给我们提供的函数，但是操作系统想要实现调用该找谁呢？还是只能自己实现？谁来把操作系统加载进内存？我发现，越接近底层的东西越让我着迷，让我感叹计算机的巧妙与伟大。

在这番好奇心的驱使下，便有了这个《开发操作系统系列》。换做以前，这个系列几乎不可能出现，因为我的精力有限，再加上水平比较菜。但如今AI时代，我可以很轻易的从零到一的写出一个简易的操作系统，还可以让AI详细讲解其中原理，这真的很棒，不输培训机构。

不行了，我发现脱离AI我这个引言只能写这一点东西，算了算了，这不是重点，重点是我能坚持把这个更新下去，就算有AI加持，还是有很多内容都需要花费比较多心思去理解。AI写当然快，但是我不能不理解其中原理，这个系列的意义不在于写出一个多么牛逼的操作系统，在于我能因为这个而学到很多东西，就像之前写游戏一样，不是为了做游戏，而是为了加强自己工程能力还有理解游戏是怎么被写出来的。如今AI时代，很多代码细节可能并不是那么重要了，但是原理一定要明白，一定要有个感性的认识，一定要拓宽自己的知识面，这样才能更好的驾驭AI。

废话不多说了，我们马上就要进入从零开发操作系统的教程了，整个系列可能就这些是我手写的了，且看且珍惜。

## 写作约定

- 像书一样叙事引导：先抛现象或问题，带着读者想，再自然引出概念——不写"为什么 X / X 是什么 / 怎么做 X"这种提纲式小标题
- 每个技术概念先给"5 岁小孩能懂"的类比（UEFI=物业、Limine=持工牌的中介、串口=电报员、页表=地址翻译员……），再上术语
- 概念先行：涉及新硬件/新机制时先讲清原理，再贴代码
- 实际踩过的坑都收录进「坑」小节——坑是最好的教材
- 代码片段配逐段讲解：这段在系统里的位置、关键写法为什么如此

## 项目约定

- 开发在 QEMU 里迭代，阶段性在真机验证
- 内核语言：Rust（`no_std`）
- 引导器：Limine Boot Protocol
- 配套代码仓库：[minecraftbucuo/MOS](https://github.com/minecraftbucuo/MOS)
- 详细技术方案见仓库根目录的方案文档
