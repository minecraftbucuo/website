## 写作约定

- 像书一样叙事引导：先抛现象或问题，带着读者想，再自然引出概念——不写"为什么 X / X 是什么 / 怎么做 X"这种提纲式小标题
- 每个技术概念先给"5 岁小孩能懂"的类比（UEFI=物业、Limine=持工牌的中介、串口=电报员、页表=地址翻译员……），再上术语
- 概念先行：涉及新硬件/新机制时先讲清原理，再贴代码
- 实际踩过的坑都收录进「坑」小节——坑是最好的教材
- 代码片段配逐段讲解：这段在系统里的位置、关键写法为什么如此

## 项目约定

- 开发在 QEMU 里迭代，阶段性在真机验证
- 内核语言：Rust（`no_std`）
- 引导器：Limine Boot Protocol
- 详细技术方案见仓库根目录的方案文档
