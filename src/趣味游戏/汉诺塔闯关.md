# 汉诺塔闯关

规则一句话：把 A 柱上的所有盘子搬到 C 柱，**每次只能移一个盘，大盘不能压小盘**。从 3 层开始，层数越高越烧脑。

## 评分标准

| 评价 | 条件 | 称号 |
| ---- | ---- | ---- |
| S | 步数 = 最少步数（$2^n - 1$） | 递归大师 |
| A | 超出最少 25% 以内 | 稳 |
| B | 超出最少 60% 以内 | 还有优化空间 |
| C | 更多 | 路是走出来的 |

走错了可以用「撤销」反悔，撤销会退步数，想拿 S 就大胆试错。

## 背后的算法

汉诺塔是递归的入门经典。要把 $n$ 个盘从 A 搬到 C，只需要三步：

1. 把上面 $n-1$ 个盘从 A 搬到 B（递归解决）
2. 把最大的盘从 A 搬到 C（一步）
3. 把那 $n-1$ 个盘从 B 搬到 C（递归解决）

写成递推式就是 $f(n) = 2f(n-1) + 1$，解得 $f(n) = 2^n - 1$。64 层的汉诺塔需要 $2^{64} - 1 \approx 1.8 \times 10^{19}$ 步——这就是「世界末日」传说的由来。

点「最优解演示」可以看到这个递归的完整执行顺序：它总是先解决上面一摞，再挪最大的盘，然后再解决一遍上面一摞。
