遗传算法求解丢番图方程（2026.8.13）

“遗传算法”中留下的作业，自己尝试了做一下，以更加理解遗传算法。
代码基本为手写，叫AI优化了一下，文字描述为AI生成。

问题描述

丢番图方程（Diophantine Equation）是形如 a₁x₁ + a₂x₂ + ... + aₙxₙ = 0 的整数方程。
给定系数向量 DIU（长度为 N=1000，每个系数在 1~10 之间），
寻找一个整数向量 g（每个分量在 -30~30 之间），使得它们的点积为 0。

为什么用遗传算法？

1000 维的丢番图方程搜索空间极其巨大（61^1000 种可能），不可能穷举。
遗传算法通过模拟自然选择、交叉和变异，在庞大搜索空间中高效逼近最优解。

算法流程

  1. 初始化种群：随机生成 100 个个体（每个个体是长度为 1000 的整数向量）
  2. 适应度评估：适应度 = |DIU · g|，值越小越优（0 表示完美解）
  3. 选择 + 变异（30%概率）：随机选一个个体变异，若变异后比最差个体更好则替换之
  4. 选择 + 交叉（70%概率）：随机选两个不同个体交叉，若子代优于父代则替换
  5. 重复 2-4，直到找到适应度为 0 的解

1. 导入库 & 随机种子

# random：用于所有随机操作（生成个体、交叉切点、变异判断等）
import random
# matplotlib：用于绘制适应度收敛曲线
import matplotlib.pyplot as plt
# numpy：提供高效的数组操作（点积、向量化计算）
import numpy as np

# 固定随机种子，确保每次运行结果一致，方便调试和复现
random.seed(42)
np.random.seed(42)

2. 个体生成函数

# N：方程中变量的个数（维度），也是每个个体的基因长度
N = 1000

# generate(n)：随机生成一个个体（候选解），长度为 n，每个基因值在 [-30, 30] 范围内
def generate(n):
    return np.array([random.randint(-30, 30) for _ in range(n)])

# 展示一个随机生成的个体（前 1000 个基因值）
generate(N)

3. 系数向量 DIU

# DIU：丢番图方程的系数向量，每个系数在 [1, 10] 范围内随机生成
# 目标是找到 g 使得 DIU · g = 0
DIU = np.array([random.randint(1, 10) for _ in range(N)])
print(DIU)

4. 遗传算法核心组件

4.1 适应度函数 fit(g)

计算 |DIU · g|，即系数向量与候选解点积的绝对值。
目标是让这个值等于 0——值越小，个体越优。

4.2 交叉操作 xover(g1, g2)

模拟生物的有性繁殖：随机选一个切点 x（1 到 len-1），
将 g1 的前 x 个基因和 g2 的后半部分拼接，产生一个混合子代。
切点避开 0 和 len，避免子代完全等于父代。

4.3 变异操作 mutate(g, rate=0.02)

模拟基因突变：以 2% 的概率独立翻转每个基因（随机替换为 [-30, 30] 内的整数）。
先 copy 再修改，避免原地修改破坏原个体。
低突变率保证搜索稳定，同时保留跳出局部最优的能力。

# fit(g)：适应度函数，计算 |DIU · g|
# DIU * g 是按元素相乘，再 .sum() 求和，abs 取绝对值
# 值越小越优，0 表示找到了完美解
def fit(g):
    return abs((DIU * g).sum())

# xover(g1, g2)：单点交叉操作
# 随机选一个切点 x（1 到 len-1），将 g1 前半段 + g2 后半段拼接
# 切点不能是 0（子代 = g2）也不能是 len（子代 = g1），这样才能产生真正的新个体
def xover(g1, g2):
    x = random.randint(1, len(g1) - 1)
    return np.concatenate((g1[:x], g2[x:]))

# mutate(g, rate=0.02)：变异操作
# 每个基因以 rate=2% 的概率独立变异为 [-30, 30] 内的随机整数
# 先 g.copy() 避免影响原个体，再逐个基因判断是否变异
def mutate(g, rate=0.02):
    g = g.copy()
    for i in range(len(g)):
        if random.random() < rate:
            g[i] = random.randint(-30, 30)
    return g

5. 种群初始化

随机生成 100 个个体组成初始种群，每个个体是长度为 1000 的整数向量。
种群规模 100 是经验值——太小则多样性不足易早熟收敛，太大则计算开销大。

# P：种群（Population），包含 100 个个体，每个个体是长度为 N 的整数向量
P = np.array([generate(N) for _ in range(100)])
# res：记录每代最优适应度，用于画收敛曲线
res = []

6. 遗传算法主循环

每轮迭代的流程：

  1. 记录当前种群中最优个体的适应度 → 如果已经为 0 则退出
  2. 以 30% 概率执行变异，70% 概率执行交叉（模拟自然界中交叉为主、变异为辅）

变异分支（30%）

  • 随机选一个个体进行变异
  • 找到种群中适应度最差的个体
  • 如果变异后的子代优于最差个体，则替换之（精英保留策略，防止种群退化）

交叉分支（70%）

  • 随机选两个不同的个体（while 循环保证 i ≠ j）
  • 交叉产生子代
  • 如果子代优于父代 i 则替换 i，否则如果优于父代 j 则替换 j
  • 如果子代不如任一父代则丢弃（不退化原则）
# 主循环：不断迭代直到找到适应度为 0 的解
while True:
    # 记录当前种群中最优个体的适应度
    res.append(min([fit(x) for x in P]))
    # 如果适应度已经为 0，说明找到了完美解，退出循环
    if res[-1] == 0:
        break

    # 以 30% 概率执行变异，70% 概率执行交叉
    # 这个比例是经验值——变异太多会退化成随机搜索，太少则可能陷入局部最优
    if random.randint(1,10)<3:
        # == 变异分支 ==
        # 随机选一个个体变异
        i = random.randint(0,len(P)-1)
        b = mutate(P[i])
        # 找到种群中适应度最差的个体
        worst_idx = np.argmax([fit(z) for z in P])
        # 只有变异后子代比最差个体更优时才替换，防止种群退化
        if fit(b) < fit(P[worst_idx]):
            P[worst_idx] = b
    else:
        # == 交叉分支 ==
        # 随机选两个不同的个体作为父代
        i = random.randint(0,len(P)-1)
        j = random.randint(0,len(P)-1)
        # while 循环保证 i 和 j 不同，避免自己和自己交叉（无意义）
        while j == i:
            j = random.randint(0,len(P)-1)
        # 交叉产生子代
        b = xover(P[i],P[j])
        # 子代优于父代 i 则替换 i
        if fit(b)<fit(P[i]):
            P[i]=b
        # 否则如果优于父代 j 则替换 j
        elif fit(b)<fit(P[j]):
            P[j]=b
        # 如果子代不如任一父代则丢弃（不退化原则）
        else:
            pass

# 输出最终适应度（应为 0）
print(res[-1])

# 绘制适应度收敛曲线
plt.plot(res)
plt.show()

关键设计要点总结

设计点说明
随机种子固定 seed=42，保证每次运行结果一致，方便调试
交叉切点范围 [1, len-1]，避免子代等于父代
变异率2% 逐基因独立变异，先 copy 再修改避免原地修改
父代选择while 循环保证 i ≠ j，避免自己和自己交叉
变异替换只在比最差个体更优时才替换，防止种群退化
交叉替换子代优于父代才替换，不退化原则
交叉/变异比例3:7（30% 变异，70% 交叉），经验最优值
种群规模100 个个体，平衡多样性与计算开销
